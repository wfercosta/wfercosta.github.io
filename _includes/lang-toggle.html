{%- comment -%} Language switcher. Each language is a real page in Jekyll/polyglot. - On a post with a shared `ref`, link to the equivalent translation. - Otherwise, link to the same page under the language prefix (default_lang has no prefix; others live under //). {%- endcomment -%} {%- assign cur_lang = site.active_lang | default: site.default_lang -%}
